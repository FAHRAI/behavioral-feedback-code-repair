# Publishing with callback-created deliveries
ActiveRecord 7.2/SQLite define Bulletin(state) and Delivery(bulletin_id,kind). Changing a bulletin to published via update! runs an after_update callback creating one delivery; it may then raise DeliveryFault. Implement PublishBatch.call(ids), where all IDs exist, drafts or published, possibly repeated. Publish in given order through normal updates. Return true if all succeed; on DeliveryFault return false with every bulletin and delivery row unchanged. Already-published records must not receive new deliveries; existing callback uses saved_change_to_state?. Never manually create deliveries or suppress callbacks.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
