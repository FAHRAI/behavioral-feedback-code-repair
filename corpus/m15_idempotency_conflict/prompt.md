# Reject conflicting reuse of an idempotency key
ActiveRecord 7.2/SQLite define PaymentRequest(request_key,amount,recipient). Implement RegisterPayment.call(key,amount,recipient) for a nonempty string key, positive integer amount and nonempty recipient string. On a new key create one row and return its integer ID. An existing key with identical amount AND recipient returns the original ID without writes. Reusing a key with either field changed raises ArgumentError and leaves all rows unchanged. Existing persisted rows count even if not created by this implementation. No uniqueness database constraint is supplied; input begins without duplicate keys. Sequential calls only.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
