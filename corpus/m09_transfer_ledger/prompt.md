# Balance transfer with a ledger write
ActiveRecord 7.2/SQLite define Wallet(balance integer >=0) and TransferLog(source_id,target_id,amount,memo), whose memo must be present. Its after_create callback can raise TransferFault after insertion. Implement WalletTransfer.call(source_id,target_id,amount,memo). Existing wallet IDs and integer amount are supplied. For positive affordable amount transfer money and create exactly one ledger row, returning true. Nonpositive amount, equal IDs, insufficient funds, invalid memo, or TransferFault must return false with all wallet/log rows unchanged. Persist through normal validated model writes.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
