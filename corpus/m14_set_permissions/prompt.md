# Stable identities when assigning a permission set
ActiveRecord 7.2/SQLite define PermissionUser(name) and PermissionGrant(permission_user_id,permission). Implement SetPermissions.call(user_id,permissions) for an existing user and array of nonempty permission strings. After every call its grant rows must equal the unique requested set, with no duplicates. Return those strings sorted. Preserve IDs of all grants that remain requested; create only missing grants and destroy obsolete grants. Empty array removes all grants for that user. Other users and their grant identities must remain unchanged. Existing data has no duplicate grants. All input is valid, and persistence callbacks do not fail in this task.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
