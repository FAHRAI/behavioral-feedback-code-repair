# A terminal transition applied exactly once
ActiveRecord 7.2/SQLite define DispatchJob(state,completed_tick,completion_count) and CompletionReceipt(dispatch_job_id,tick). Implement CompleteDispatch.call(id,tick) for an existing job and integer tick. For pending or running jobs set state completed, record supplied tick, increment completion_count by one, create exactly one receipt with that tick, and return true. For an already completed job return true without changing any row, even if it has no receipt (do not backfill). For a cancelled job return false without any writes. Repeated calls must preserve the original completion tick and count. These four states are exhaustive. Persistence succeeds; no concurrent workers.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
