# A failed batch inside its caller transaction
ActiveRecord 7.2/SQLite define Bin(quantity integer >=0), and unrelated CallerNote(text). Implement AdjustBins.call(changes) for ordered [existing_bin_id,integer_delta] pairs. Apply every change and return true, or return false if any resulting quantity is invalid, leaving all bins unchanged by that call. The method may run inside a caller-owned transaction: failure must neither commit partial bin updates nor roll back caller writes before/after the call. Do not raise on this expected validation failure. Empty changes succeed; repeated IDs apply sequentially. Do not commit or roll back the caller transaction yourself.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
