# Persistent per-account event deduplication
ActiveRecord 7.2/SQLite define CreditAccount(balance) and CreditEvent(credit_account_id,event_key,amount). Implement ApplyCredit.call(account_id,key,amount) for an existing account, nonempty string key and positive integer amount. A previously unseen (account_id,key) credits balance once, creates one event and returns :applied. Repeating that pair returns :duplicate without changing any row (the same pair is always supplied the same amount). Different accounts may use the same key. Persisted events are authoritative, including records created before the first call to this implementation. No process-local cache may replace checking durable state. Single-process sequential calls only; concurrency correctness is out of scope.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
