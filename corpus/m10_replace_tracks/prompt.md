# Replace an ordered child collection
ActiveRecord 7.2/SQLite define Playlist(name) and Track(playlist_id,title,position). Track validates title presence; before_destroy may raise TrackFault for a selected existing row. Implement ReplaceTracks.call(playlist_id,titles) for an existing playlist and ordered string array. Destroy its old tracks using callbacks, then create tracks in supplied order with zero-based positions; return true (empty input clears). On RecordInvalid or TrackFault return false and restore every row including original IDs and positions. Other playlists must remain unchanged. Do not use delete_all or skip callbacks.
Return Ruby code only. No concurrent callers or writers are involved. Do not modify models/schema, bypass callbacks/validation, or access external services.
